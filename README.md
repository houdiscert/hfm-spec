# Houdiscert Flavored Markdown (HFM) Specification

## I. Simple Markdown

### 1. Asterisks

To make text bold, you should wrap it in two asterisks, like this:
```hfm
**This text is bold.**
```
Output:
**This text is bold.**

To make text italic, you should wrap it in only one asterisk, like this:
```hfm
*This text is italic.*
```
Output:
*This text is italic.*

Text should be able to be made both bold and italic by wrapping in in
three asterisks, like this:
```hfm
***This text is both bold and italic***
```
Output:
***This text is both bold and italic***
